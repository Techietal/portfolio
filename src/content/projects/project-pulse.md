## What it does
An AI-powered project monitoring system that orchestrates specialised agents to produce project health reports.

## What I built
- A **sequential agent pipeline** with typed state management in **LangGraph**.
- **ChromaDB**-backed historical storage for trend analysis.
- A **Streamlit** dashboard with per-project risk metrics, fed from **Azure DevOps**.
